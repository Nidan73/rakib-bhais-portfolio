# rakib-bhais-portfolio

Portfolio for Rakib - study abroad executive, Dhaka.

Next.js 15 + TypeScript + Tailwind v4. UI is a pixel-exact port of `rakib-portfolio (1).html` (kept as reference).

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # verify before pushing
npm run typecheck  # tsc --noEmit
```

See `AGENTS.md` for project rules and current state.
